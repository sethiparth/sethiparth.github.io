03 Projects

Case studies

Systems shipped at scale — a from-scratch rendering engine, a 10x throughput rewrite, a five-nines reliability framework, and a maintenance platform protecting half a million customers.

Sage Rendering Engine

>$1B channel powered

Architected a high-performance Handlebars scripting engine from scratch, taking full ownership of replacing Salesforce's legacy E360 platform end to end. Designed the two-step gRPC API and a generic helper framework — 40+ scripting helpers reaching 100% functional parity with legacy behavior. The engine now powers the email channel generating more than $1B in annual revenue, with critical functionality delivered two releases ahead of schedule.

  • Java
  • gRPC
  • Architecture
  • Lead

Email Service 10x Throughput

10M → 40M / hr

Led the team through a full redesign of email delivery, taking throughput from 10M to 40M emails per hour by optimizing AWS DynamoDB batch loads and streamlining intermediate step execution. Introduced Redis for deduplication to eliminate redundant sends at scale.

  • AWS
  • DynamoDB
  • Redis
  • Performance

Five-Nines Availability Framework

98% → 99.999%

Architected a validation framework that raised email service availability from 98% to 99.999%. Cut PagerDuty alerts by more than 10 per week and turned future bug fixes into minor, low-risk code changes. Built as the source of truth for on-call reliability.

  • Reliability
  • Validation
  • On-call

EC2 Reboot-on-Degrade

556K+ customers protected

Rearchitected the customer maintenance service to let EC2 send "reboot" events across 25 public regions when hardware degraded, safeguarding instance data for more than 556,000 customers. Part of a broader scheduler overhaul that removed manual daily scripts.

  • AWS
  • EC2
  • Distributed Systems

AI-Orchestrated Org Provisioning & Test Automation

~4 hrs/org → automated

Architected an agentic automation pipeline using Claude and AI agents to replace a manual ~4-hour-per-org workflow — provisioning a new org, executing preview and real email sends, and standing up integration and daily service-health tests. Eliminated repetitive setup toil and reclaimed multiple weeks of aggregate team effort.

  • Claude
  • AI Agents
  • Automation
  • Test Infrastructure
  • Salesforce
